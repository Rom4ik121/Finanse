# Возможности FinWise

Языки интерфейса: **ru / en / uz**. Базовая валюта задаётся в настройках (по умолчанию RUB; в демо часто UZS).

---

## Главная (Dashboard)

- Суммарный баланс всех активных счетов **в базовой валюте** (FX через RateBook).  
- Предупреждение, если нет курса для части счетов.  
- Баннеры напоминаний (долги / подписки / цели), до 3 штук.  
- Быстрое добавление дохода / расхода (dual button + sheet).  
- Кнопка **Аналитика**.  
- Ярлыки: цели, долги, подписки, валюты.  
- Обновление (refresh).

---

## Аналитика

- Периоды: 7 / 30 / 90 / 180 / 365 дней / всё время.  
- KPI: доходы, расходы, итог за период **в базовой валюте**.  
- Круговая диаграмма категорий расходов.  
- Линейный график динамик доходов/расходов.  
- Пустой период → empty state.  
- Агрегация и конвертация в **один проход** (RateBook), без N× запросов курсов в БД.

---

## Операции (Transactions)

- Список с группировкой: день / неделя / месяц.  
- **Пагинация** (первая порция ~60, кнопка «Показать ещё»).  
- Поиск по категории, комментарию, тегам (с debounce).  
- Фильтры: тип, категория, диапазон дат.  
- CRUD операции (fullscreen-формы).  
- Связь с целью / долгом через use cases при соответствующих сценариях.  
- Категории локализуются в списке (`localize_category_name`).

---

## Счета (Accounts)

- CRUD счетов: имя, валюта, иконка, цвет, начальный баланс.  
- Отображение баланса и приблизительного эквивалента в базовой валюте.  
- Удаление с подтверждением (каскад транзакций на уровне БД).

---

## Цели (Goals)

- Цель: название, сумма, приоритет 1–5, дедлайн.  
- Прогресс `current / target`; статус «завершена».  
- Взнос со счёта: только счета в **базовой валюте** (цели ведутся в base).  
- При достижении цели — уведомление (если включены milestones).

---

## Долги (Debts)

- Направления: **я должен** / **мне должны**.  
- Сумма, остаток, валюта, процент, срок, комментарий.  
- Создание с записью кассы (опционально): валюта долга = валюта счёта.  
- Погашение: только счета в **валюте долга**.  
- Проценты — расчёт для отображения (simple interest), не капитализируются автоматически.  
- Итоги «должен / мне должны» в базовой валюте + предупреждение о missing FX.

---

## Подписки (Subscriptions)

- Периодичность: месяц / год.  
- Привязка к счёту и категории.  
- Календарь ближайших списаний.  
- `ProcessDueSubscriptions`: **одно списание за каждый** пропущенный период (catch-up).  
- Итоги «в месяц / в год» в базовой валюте.

---

## Валюты (Currencies)

- Каталог fiat + crypto из `assets/data/currencies.json` (+ БД).  
- Список курсов к базовой валюте; поиск тикера.  
- Конвертер пар (Из / В) с fullscreen-пикером.  
- «Обновить курсы» → HTTP provider (fiat USD book + Binance / CoinGecko).  
- Конвертация: прямой курс, обратный, cross через pivots (USD и др.).  
- Дополнительно сохраняются USD-якоря (удобно для BTC↔USD при базе UZS).

---

## Настройки (Settings)

Секции (аккордеон):

- **Внешний вид** — тема light / dark / system.  
- **Валюта и язык** — default currency, ru/en/uz; смена валюты может переименовать код на счетах (см. ограничения).  
- **Курсы** — интервал автообновления.  
- **Уведомления** — master + долги / подписки / цели; время напоминания `HH:MM`.  
- **Безопасность** — PIN (PBKDF2), биометрия (Windows Hello / mobile).  
- **Данные** — экспорт JSON/CSV/PDF, backup/restore, полный wipe.  
- Переходы на цели / долги / подписки / валюты.

После wipe пересоздаётся счёт «Наличные» в текущей базовой валюте настроек.

---

## Безопасность

- Экран блокировки при наличии PIN / биометрии.  
- PIN хранится как hash+salt, не plaintext.  
- Биометрия: `flet_local_auth`; в тестах stub через `FINANCE_BIOMETRIC_OK=1`.

## Уведомления

| Канал | Реализация |
|--------|------------|
| В приложении | `NotificationService` очередь |
| Windows | `winotify` toast |
| Android | `flet-android-notifications` + permissions в `pyproject.toml` / `flet.toml` |

`FINANCE_DISABLE_PUSH=1` — без OS push (удобно для pytest).

---

## Ограничения (важно знать)

1. Смена базовой валюты в настройках **может менять код валюты** у счетов без FX-пересчёта сумм — это не полноценная конвертация портфеля.  
2. Денежные суммы квантуются до **2 знаков** — суб-центовые crypto-суммы в ledger не поддерживаются.  
3. Цель не имеет отдельного поля currency — UI считает её в base.  
4. Операции «цель / долг» из произвольного add_transaction без проверок направления возможны на уровне домена; UI-сценарии contribute/repay защищены.
